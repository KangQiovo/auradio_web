# 官网维护与验证

只维护 main，保留既有 GitHub Pages 发布流程。先核对当前内容，修改相关文件，再执行类型检查、行为测试、构建与浏览器交互验证；只发布 dist。

专辑体验由共享曲目数据、可缓存的封面取色和 React 交互组件构成。封面、文字与背景协同过渡；手机支持横向选曲和封面手势，纵向滚动不被劫持。动态偏好、图片失败、快速重复切换、第三方播放器关闭与本地音频释放均需验证。

官网不披露应用具体版本或更新记录。未来消息只保留期待式摘要。网页交互不能当作客户端功能承诺，第三方作品不能当作获得统一原生曲库授权。

官方播放器的网络可用性单独观测。可重复的界面测试使用明确标记的封面与播放器测试资源，不将它们表述为真实歌曲播放成功。本地音频解码、播放和时间控制使用浏览器实际媒体事件验证。
