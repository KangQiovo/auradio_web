# Auradio 官网设计规格

## 目的
面向想了解 Auradio 的音乐听众，提供真实、可操作、有明确版本边界的中文产品官网。目标不是把预发布软件包装成成熟全平台音乐服务。

## 信息基线
2026-09-21 核对的最新 Android 预发布为 0.1.0-demo10-fix2，发布于 2026-08-25；对应提交 81573bc1aed803a1b33f5d155c845660686e1c6b。旧 main 的 Flutter README 不是当前发布线的功能基线。应用源码当前私有；官网代码公开不改变这一状态。只整理适合公开的功能摘要，不复制内部协作资料和安装包。

## 视觉
沿用 Auradio 原有 A + 声波品牌。深蓝黑、浅纸色和青绿色构成克制的编辑式页面；大字号与留白、细分隔线、宽幅视觉舞台构成节奏。不用霓虹渐变、装饰性粒子、假数据或重复卡片墙。强动态仅用于主动进入的声音实验与适量滚动反馈；默认尊重减少动态。

## 结构
首页 / 体验室 / 当前进度 / 使用与隐私 / 技术鸣谢 / 404。Astro 预渲染内容，React islands 管理需要交互的表面，TypeScript 检查组件。Motion 负责控件与状态过渡，GSAP 负责滚动关联，Three.js 负责按需加载的声音雕塑。

## 核心行为
试听音频由本项目合成，明确标注，不自动出声。支持用户选择单个本地音频，使用 object URL，限制 100 MiB、验证格式、报错可见、替换/卸载撤销 URL。真实播放、暂停、进度拖动、音量与 Web Audio 分析；无上传端点。主题切换为网页示意，绝不标成客户端实拍。视觉模式、强度、播放状态可交互。关闭动态、页面不可见或场景离屏时暂停循环，释放 WebGL 资源；无 WebGL 时保留静态插图与内容。

## 内容边界
公开下载没有开放，不放私有资源下载假入口。七个平台仅描述已验证的官方网页/应用入口，不承诺原生账号、统一歌单、播放地址、会员或下载接入。Android 之外没有公开版本，不给承诺日期。站点无分析 SDK，不读取账号或定位；托管服务自身日志不能保证不存在。

## 验收
领域单元测试；Astro/TypeScript 检查；生产构建；桌面、手机、减少动态与无 JavaScript 检查；真实音频播放/拖动/本地文件/错误反馈；无横向溢出；所有内部路由和按钮有效；生产 JS 无私有凭据、私有下载链接、用户路径。仅 dist 发布到 GitHub Pages。
