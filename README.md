# Auradio 官网

Astro + React + TypeScript 多页官网。Motion 管理专辑与界面过渡，GSAP 管理原生滚动关联，Three.js 用于本地音频声场。

生产域名为 https://auradio.kangqiovo.com/。只在 main 维护与发布，不新建备选分支或草稿 PR。

## 本地运行

开发环境：Node.js 22.12+。

```sh
npm ci
npm run dev
```

```sh
npm test
npm run check
npm run build
npm start
```

便携包包含 dist 时可双击 Windows 的 start.cmd，或在 macOS / Linux 上运行 sh start.sh。启动器只提供本机静态文件服务；开发修改仍需重新构建。

默认本机预览使用 /auradio_web/。生产通过 AURADIO_BASE=/ 构建。保留现有 GitHub Pages 部署链路，仅发布 dist，不发布仓库根目录。

## 内容与媒体

官网只介绍产品阶段和已存在的公开能力，不公布客户端具体版本号、发布日志、内部文档或详细路线。依赖软件的版本仅用于可重复构建，和客户端产品信息不同。

精选作品为《自由的你》《于是》和《G.E.M. (Get Everybody Moving)》。作品身份见 src/lib/albums.mjs；名称与官方目录对应，不使用同名翻唱或其他歌曲替代。第三方播放器仅在用户点击时加载，切换作品会卸载原播放器。Apple Music 未登录时提供 30 秒片段，其他登录状态和平台的实际开放范围以其服务为准。《自由的你》对应官方约 48 秒试听版，并非本站剪辑。

封面从官方服务加载，浏览器用小尺寸像素采样提取色板，缓存复用并设置渐变环境色。跨域或网络不允许取色时使用备用色。官方嵌入播放器的内容不被本站提取或分析；实时声场仅使用用户主动选择的本地音频。本地文件不上载、不保存，只在当前页面播放。

网站不存储、缓存或再分发音乐录音；版权与平台限制由各自权利人和平台决定。歌曲展示不构成艺人对 Auradio 的代言或合作。沿用获准品牌图标，不夹带私有应用资源。
