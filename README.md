# Auradio 官网

Astro + React + TypeScript 静态官网，使用 Motion、GSAP 和 Three.js。生产域名为 https://auradio.kangqiovo.com/ 。按维护者要求直接维护 main，不创建额外分支。

## 运行与构建

使用 Node.js 22.12 或以上兼容版本。安装依赖后运行：

```sh
npm ci
npm run dev
npm test
npm run check
npm run build
```

便携包包含 dist 时可双击 Windows 的 start.cmd，或运行 sh start.sh。便携构建保留 /auradio_web/；生产使用 AURADIO_BASE=/ 构建。现有 Pages 流程验证后只发布 dist，不发布源码目录。

## 内容边界

不公布客户端具体版本号、更新日志、内部资料或详细路线。专辑颜色仅限首页精选聆听及体验正文，不写入 html/body。G.E.M. 的宣传说明按要求留空；作品正式名称保持准确。

三首作品继续使用官方嵌入播放器，不下载、剪辑、缓存或再分发录音，也不绕过平台限制。封面按需取色和缓存色板。官网交互不代表客户端功能或艺人代言。

## 真实频谱与交互

64 个对数频段来自实际 Web Audio 分析，统一驱动频谱条和可见声场，不靠总音量模拟整幅图案。复用缓冲区，播放数据不逐帧进入 React。静音时无假节拍。

鼠标、触屏和键盘可在未播放时拨散图案；短暂位移自然衰减回位。离屏、后台或减少动态时停止连续绘制。

官方 iframe 不直接开放音频节点。可选“同步当前标签页声音”由用户点击，并通过浏览器原生选择器授权后读取标签页声音。画面轨道禁用、不读取，不调用麦克风，不录制、不上传。选成窗口或屏幕立即拒绝；可随时停止。不同浏览器及受保护内容可能不提供音频轨道，届时不伪造数据。本地音频无需此共享权限。

## 验证

原有界面回归与新增 scripts/reactive-qa.py 分别检查局部染色、移动布局、真实音频频段、未播放交互及授权同步。新增同步回归使用浏览器真实标签页共享与原创测试信号，不将这些结果冒称为三首版权歌曲的实测。第三方媒体的实际可用性单独记录。
